カーソルが点滅し、「？」が現れて雲のようにほどけ、続いて「！」が現れる演出。

- `index.html` — イントロを組み込んだトップページ（当時のもの）
- `intro.js` — 演出の本体（元の置き場所は `js/intro.js`）
- `intro.css` — 演出用スタイル（元の置き場所は `css/intro.css`）

## 復元方法

1. `index.html` をリポジトリ直下の `index.html` に戻す
2. `intro.js` を `js/` に、`intro.css` を `css/` に戻す

フォント（`fonts/KikaiChokoku.woff2`、`fonts/TetsubinGothic.woff2`）は現行ツリーに残してある。
なお `js/intro.js` と `css/intro.css` は、現行ツリーにも未使用のまま残してある。
